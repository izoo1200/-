이벤트 발생

AI와 함께 만든 게임

이 게임은 제작자의 기획과 AI의 도움을 바탕으로 개발되었습니다.

AI의 도움을 받은 부분

AI는 게임 개발 과정에서 코드 작성, 프로그래밍 구현 및 코드 수정을 보조하는 도구로 활용되었습니다.

게임 규칙과 시스템 기획, UI 디자인 및 카드 제작은 제작자가 직접 진행했습니다.

개발 과정

01
게임 규칙 구성

AI의 도움 없이 제작자가 직접 게임 규칙과 시스템을 구상했습니다.

02
코드 작성 및 기능 구현

기획한 규칙을 실제 게임으로 구현하기 위해 AI의 도움을 받아 코드를 작성했습니다.

03
플레이 테스트 및 규칙 개선

게임을 직접 플레이하며 발견한 규칙 오류를 AI의 도움을 받아 수정하고 개선했습니다.

04
UI 디자인 및 카드 제작

AI의 도움 없이 제작자가 직접 UI를 디자인하고 카드를 제작했습니다.

05
디자인 적용 및 최종 구현

직접 제작한 UI 디자인과 카드를 게임에 적용해 최종 결과물을 완성했습니다.

게임을 즐겨주셔서 감사합니다!

🃏 카드 도감

게임에 등장하는 카드와 효과를 한눈에 확인할 수 있어.

📖 게임 규칙 안내 (게임 시작 전에 읽어주세요)

1. 승리 조건

  • 최후의 생존자가 승리합니다.
  • 체력이 0이 되면 탈락합니다. 단, 손패에 부활 카드가 있을 경우 자동으로 부활합니다. 부활 카드 사용 후 손패가 0장이 되면 카드 1장을 뽑은 상태로 부활합니다.

2. 게임 시작

  • 시작 체력은 30으로 설정합니다.
  • 시작 손패는 5장 또는 10장 중 방장이 선택합니다.

3. 행동 방식

  • 자신의 차례에 생존한 상대 한 명을 지정하고 카드 1장을 사용합니다.
  • 카드를 사용할 때 상대의 대응 유형을 예측해야 합니다.
  • 사용한 카드는 다시 뽑습니다.

4. 공격 및 대응 판정

  • 예측 성공: 공격이 적중하고 카드 효과가 발동합니다.
  • 반격 대응: 예측에 실패하면 공격은 무효 처리되며, 반격 카드에 명시된 수치만큼 공격자에게 피해를 줍니다.
  • 기타 대응: 예측에 실패하면 공격자의 카드는 효과 없이 소모되며, 대상의 대응 효과가 적용됩니다.
  • 무대응: 상대가 대응하지 않을 경우 예측 결과와 관계없이 공격이 적중합니다.
  • 반격 카드는 대응 시에만 사용할 수 있습니다.

5. 상태 효과

  • 독과 화상은 매 턴 피해를 줍니다.
  • 상태 효과 회복 포션을 사용하면 해당 상태 효과가 해제됩니다.

6. 제한 시간 및 라운드

  • 행동 제한 시간은 30초입니다.
  • 제한 시간 내에 행동하지 않을 경우 손패 1장이 무작위로 제거되고 차례가 종료됩니다.
  • 10라운드부터 모든 피해량이 2배로 적용됩니다.
