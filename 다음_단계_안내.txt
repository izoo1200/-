별빛 결투 — 방 만들기/초대 코드 단계

1. index.html 파일을 다운로드합니다.
2. GitHub 저장소에서 기존 index.html을 이 파일로 교체합니다.
3. Commit changes를 눌러 저장합니다.
4. 배포가 반영된 뒤 https://izoo1200.github.io/-/ 를 새로고침합니다.
5. ✨ 멀티플레이 연결 설정 → 저장된 URL/키로 연결 테스트를 확인합니다.
6. 🌟 새 대전방 만들기를 누르면 초대 코드와 초대 링크가 나옵니다.
7. 친구는 초대 링크를 열고 본인의 Supabase URL/공개용 키를 입력한 다음 연결 테스트 → 코드로 입장을 누릅니다.

중요:
- 이 단계는 방 생성과 초대 코드 입장만 구현합니다. 실시간 카드 전투 동기화는 아직 구현되지 않았습니다.
- Supabase 정책이 MVP 테스트용으로 넓게 열려 있다면 공개 배포 전에 반드시 보안을 강화해야 합니다.
- Publishable/anon 공개용 키만 사용하세요. service_role/secret 키를 브라우저에 넣지 마세요.
